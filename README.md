### `cat /etc/manifesto`

> *"Write programs that do one thing and do it well. Write programs to work together. Write programs to handle text streams, because that is a universal interface."*  
> — **Doug McIlroy** (Unix Philosophy)

- 🐧 **Free Software First:** Staunch believer in user autonomy, open auditability, and software freedom governed under **copyleft (GNU GPLv3)**.
- ⚡ **Local-First & Offline-Ready:** Prioritizing tools that operate without telemetry, subscription walled-gardens, or vendor lock-in.
- 🗄️ **Homelabbing & Self-Hosting:** Running independent services, experimenting with private cloud infra, and reclaiming the **Indie Web**.
- 🔐 **Entropy & Cryptography:** Exploring hardware-level primitives, CPU on-chip randomness (`RDRAND`), and distributed cryptographic integrity.
